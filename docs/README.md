## 🎯 시스템 특징

### ✨ 핵심 기능
- **독립적인 시설관리 시스템**: 기존 ERPNext와 분리된 전용 시스템
- **자동 반복 작업**: 일간/주간/월간 작업 자동 생성
- **GPS 기반 위치 검증**: 정확한 현장 출입 관리
- **체크리스트 관리**: 표준화된 작업 절차
- **모바일 최적화**: 현장 작업자를 위한 모바일 인터페이스

### 🏗️ 시스템 구조
```
시설관리 프로젝트 → 작업 지시서 → 현장 작업 (자동 생성)
                                      ↓
현장 작업자 ← 배정 ← 현장 작업 → 현장 출입 관리
```

### 📱 지원 플랫폼
- **웹 브라우저**: Chrome, Safari, Firefox, Edge
- **모바일**: iOS Safari, Android Chrome
- **태블릿**: iPad, Android 태블릿
- **API**: REST API를 통한 외부 시스템 연동

## 👥 사용자 역할

### 🔧 시설관리 관리자
- 시설관리 프로젝트 생성 및 관리
- 작업 지시서 작성 및 템플릿 관리
- 현장 작업자 배정 및 스케줄 관리
- 작업 진행 현황 모니터링
- 품질 평가 및 보고서 검토

### 👷 현장 작업자
- 배정된 현장 작업 수행
- 현장 출입 체크인/체크아웃
- 체크리스트 작업 완료
- 작업 사진 및 보고서 제출
- 작업 진행 현황 업데이트

## 🚀 빠른 시작

### 1. 시스템 접속
```
https://your-domain.com
→ 현장관리 워크스페이스 선택
```

### 2. 첫 프로젝트 생성 (관리자)
```
시설관리 프로젝트 → 새로 만들기
→ 기본 정보 입력 → 저장
```

### 3. 작업 지시서 생성 (관리자)
```
작업 지시서 → 새로 만들기
→ 프로젝트 연결 → 작업자 배정 → 저장
```

### 4. 현장 작업 수행 (작업자)
```
내 현장 작업 → 오늘 작업 선택
→ 작업 시작 → 체크리스트 수행 → 작업 완료
```

## 📊 주요 DocType

### 🏢 Work Project (시설관리 프로젝트)
- 고객과의 시설관리 계약 단위
- ERPNext Project와 연결
- 계약 정보 및 서비스 주기 관리

### 📋 Work Task (작업 지시서)
- 반복 가능한 작업 템플릿
- 자동 반복 설정 지원
- 체크리스트 템플릿 연결

### 🔧 Work Session (현장 작업)
- 실제 수행되는 개별 작업 인스턴스
- Work Task에서 자동 생성
- GPS 기반 체크인/체크아웃
- 체크리스트 수행 결과 관리

### 👷 Work Employee (현장 작업자)
- ERPNext Employee 확장
- 시설관리 전용 정보 관리
- 성과 및 가용성 추적

### 🏢 Work Attendance (현장 출입 관리)
- ERPNext Attendance 확장
- GPS 위치 검증
- 사진 인증 및 출석 점수

- **Language**: Python 3.8+

### Frontend
- **Framework**: Frappe UI
- **Language**: JavaScript ES6+
- **Mobile**: Responsive Web Design
- **Maps**: Google Maps API

### Infrastructure
- **Server**: Ubuntu 20.04+
- **Web Server**: Nginx
- **Process Manager**: Supervisor
- **Cache**: Redis
