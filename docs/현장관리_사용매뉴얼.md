## 🎯 시스템 개요

### 목적
webiz 현장관리 시스템은 시설관리 업무의 디지털화를 통해 효율적인 현장 작업 관리를 제공합니다.

### 주요 특징
- ✅ **독립적인 시설관리 시스템**: 기존 ERPNext와 분리된 전용 시스템
- ✅ **자동 반복 작업**: 일간/주간/월간 작업 자동 생성
- ✅ **GPS 기반 위치 검증**: 정확한 현장 출입 관리
- ✅ **체크리스트 관리**: 표준화된 작업 절차
- ✅ **모바일 최적화**: 현장 작업자를 위한 모바일 인터페이스

### 시스템 구성
```
시설관리 프로젝트 → 작업 지시서 → 현장 작업 (자동 생성)
                                      ↓
현장 작업자 ← 배정 ← 현장 작업 → 현장 출입 관리
```

## 🗂️ 워크스페이스 구조

### 1. 현장 작업자 카드
- **내 현장 작업**: 배정된 작업 목록 및 진행 현황
- **현장 출입 기록**: GPS 기반 체크인/체크아웃 관리
- **작업 진행 현황**: 실시간 작업 상태 확인
- **작업 사이트 정보**: 현장 위치 및 상세 정보

### 2. 시설관리 관리자 카드
- **시설관리 프로젝트**: 계약 기반 프로젝트 관리
- **작업 지시서**: 작업 템플릿 및 반복 설정
- **현장 작업자 관리**: 작업자 정보 및 성과 관리
- **현장 출입 관리**: 전체 출입 현황 모니터링

### 3. ERPNext 연동 카드
- **체크리스트 템플릿**: 표준 작업 절차 관리
- **고객 사이트 관리**: 작업 현장 정보
- **반복 작업 설정**: 자동 스케줄링
- **Project/Task/Employee**: 기존 ERPNext 연동

### 4. 공통 사용 카드
- **고객 정보**: 계약 고객 관리
- **계약 정보**: 서비스 계약 관리

## 🔄 업무 프로세스

### Phase 1: 프로젝트 설정
1. **시설관리 프로젝트 생성**
   - 고객 계약 정보 입력
   - 서비스 유형 및 주기 설정
   - 계약 기간 및 금액 설정

2. **작업 지시서 작성**
   - 작업 내용 및 절차 정의
   - 체크리스트 템플릿 연결
   - 예상 소요시간 설정

### Phase 2: 작업자 배정
1. **현장 작업자 등록**
   - 기본 정보 및 기술 수준 입력
   - 작업 가능 지역 설정
   - 근무 시간 및 가용성 설정

2. **작업 배정**
   - 작업 지시서에 작업자 배정
   - 스케줄 및 우선순위 설정
   - 자동 반복 설정 (필요시)

### Phase 3: 자동 작업 생성
1. **반복 작업 설정**
   - 일간/주간/월간 주기 선택
   - 실행 요일 및 시간 설정
   - 시작일/종료일 설정

2. **현장 작업 자동 생성**
   - 설정된 주기에 따라 자동 생성
   - 작업자에게 자동 배정
   - 알림 및 스케줄 업데이트

### Phase 4: 현장 작업 수행
1. **작업 시작**
   - GPS 기반 현장 체크인
   - 작업 시작 시간 기록
   - 체크리스트 항목 확인

2. **작업 진행**
   - 체크리스트 항목별 완료 처리
   - 작업 사진 촬영 및 업로드
   - 특이사항 기록

3. **작업 완료**
   - 모든 체크리스트 완료 확인
   - 품질 평가 및 고객 피드백
   - GPS 기반 현장 체크아웃

## 🔧 주요 기능 상세

### 시설관리 프로젝트
**생성 방법:**
1. 시설관리 관리자 → 시설관리 프로젝트 → 새로 만들기
2. 기본 정보 입력:
   - 프로젝트 제목
   - 연결할 ERPNext Project 선택
   - 계약 유형 (시설관리/청소/보안/유지보수/종합관리)
   - 서비스 주기 (일간/주간/월간/분기)
3. 계약 정보 입력:
   - 계약 시작일/종료일
   - 월 계약금액
   - 청구 주기
   - 주 담당자

**주요 기능:**
- 자동 제목 생성 (프로젝트명 + 계약유형)
- 계약 금액 자동 계산
- 연결된 ERPNext Project 정보 자동 가져오기

### 작업 지시서
**생성 방법:**
1. 시설관리 관리자 → 작업 지시서 → 새로 만들기
2. 기본 정보 입력:
   - 작업 제목
   - 시설관리 프로젝트 선택
   - 작업 사이트 선택
   - 체크리스트 템플릿 선택
3. 작업자 배정:
   - 담당 직원 선택
   - 예상 소요시간 입력
   - 우선순위 설정
4. 반복 설정 (템플릿인 경우):
   - 자동 반복 활성화
   - 반복 주기 및 요일 설정
   - 반복 시작일/종료일

**주요 기능:**
- 템플릿 기능으로 반복 사용
- 현장 작업 자동 생성
- 다음 실행일 자동 계산
- 생성된 세션 수 추적

### 현장 작업
**작업 흐름:**
1. **작업 시작**
   - "작업 시작" 버튼 클릭
   - GPS 위치 자동 수집
   - 체크인 시간 기록

2. **체크리스트 수행**
   - 각 항목별 완료 처리
   - 필수 항목 확인
   - 작업 사진 첨부

3. **작업 완료**
   - "작업 완료" 버튼 클릭
   - 필수 체크리스트 완료 확인
   - GPS 위치 재확인
   - 자동 Timesheet 생성

**주요 기능:**
- 실시간 작업 시간 추적
- 자동 초과근무 계산
- 완료율 실시간 표시
- 모바일 최적화 인터페이스

### 현장 작업자 관리
**등록 방법:**
1. 시설관리 관리자 → 현장 작업자 관리 → 새로 만들기
2. 기본 정보:
   - ERPNext Employee 선택 (자동 정보 가져오기)
   - 상태 (Active/Inactive/On Leave/Terminated)
3. 시설관리 정보:
   - 시설관리 기술 (청소, 보안, 전기, 배관 등)
   - 자격증 정보
   - 작업 가능 지역
   - 기술 수준 (초급/중급/고급/전문가)
4. 근무 정보:
   - 근무 가능 요일
   - 선호 근무 시간
   - 일일 최대 근무시간
   - 시간당 급여

**주요 기능:**
- 자동 작업량 추적
- 평균 평점 계산
- 가용성 자동 체크
- 성과 분석 리포트

### 현장 출입 관리
**체크인 프로세스:**
1. 현장 도착 후 "체크인" 버튼 클릭
2. GPS 위치 자동 수집
3. 인증 사진 촬영 (선택사항)
4. 현장과의 거리 자동 계산
5. 위치 검증 (100m 이내 권장)

**체크아웃 프로세스:**
1. 작업 완료 후 "체크아웃" 버튼 클릭
2. GPS 위치 재확인
3. 퇴근 인증 사진 촬영
4. 총 근무시간 자동 계산
5. 출석 점수 자동 산정

**주요 기능:**
- GPS 정확도 측정
- 현장으로부터 거리 계산
- 자동 출석 점수 계산
- ERPNext Attendance 자동 연동

## 📱 모바일 사용법

### 현장 작업자 모바일 가이드

#### 1. 작업 목록 확인
- "내 현장 작업" 메뉴 접속
- 오늘/이번주 배정된 작업 확인
- 작업 상태별 필터링 (예정/진행중/완료)

#### 2. 현장 체크인
```
1. 현장 도착
2. "현장 출입 기록" → "체크인"
3. GPS 위치 허용
4. 인증 사진 촬영 (선택)
5. 체크인 완료 확인
```

#### 3. 작업 수행
```
1. "내 현장 작업" → 해당 작업 선택
2. "작업 시작" 버튼 클릭
3. 체크리스트 항목별 수행:
   - 각 항목 클릭하여 완료 처리
   - 필요시 사진 첨부
   - 특이사항 메모 작성
4. 모든 필수 항목 완료 확인
```

#### 4. 작업 완료
```
1. "작업 완료" 버튼 클릭
2. 필수 체크리스트 완료 확인
3. 품질 평가 입력 (1-5점)
4. 완료 사진 첨부
5. 고객 피드백 입력 (선택)
```

#### 5. 현장 체크아웃
```
1. "현장 출입 기록" → "체크아웃"
2. GPS 위치 재확인
3. 퇴근 인증 사진 촬영
4. 하루 작업 완료
```

### 모바일 최적화 기능
- **원터치 체크인/체크아웃**: GPS 자동 수집
- **오프라인 모드**: 네트워크 불안정 시 로컬 저장
- **푸시 알림**: 작업 시작 시간 및 중요 알림
- **음성 메모**: 텍스트 입력 대신 음성 기록
- **QR 코드 스캔**: 빠른 현장 인식

## 🔧 문제해결 가이드

### 자주 발생하는 문제

#### 1. GPS 위치 인식 불가
**증상:** 체크인/체크아웃 시 위치 정보 수집 실패

**해결방법:**
- 브라우저 위치 권한 확인
- GPS 기능 활성화 확인
- 실외에서 재시도
- 수동 체크인 옵션 사용

#### 2. 체크리스트 항목이 로드되지 않음
**증상:** 작업 시작 후 체크리스트가 비어있음

**해결방법:**
- 작업 지시서에 체크리스트 템플릿 연결 확인
- 페이지 새로고침
- "체크리스트 다시 로드" 버튼 클릭

#### 3. 작업 완료 버튼이 비활성화됨
**증상:** 모든 작업을 완료했지만 완료 버튼 클릭 불가

**해결방법:**
- 필수 체크리스트 항목 완료 확인
- 빨간색 표시된 미완료 항목 처리
- 필수 사진 첨부 확인

#### 4. 자동 반복 작업이 생성되지 않음
**증상:** 설정한 시간에 현장 작업이 자동 생성되지 않음

**해결방법:**
- 작업 지시서의 "자동 반복 활성화" 체크 확인
- 반복 시작일/종료일 설정 확인
- 반복 요일 설정 확인
- 시스템 관리자에게 스케줄러 상태 문의

### 성능 최적화 팁

#### 관리자용
- 대량 데이터 조회 시 날짜 범위 제한
- 불필요한 첨부파일 정기 정리
- 완료된 오래된 작업 아카이브
- 정기적인 데이터베이스 최적화

#### 작업자용

- 고해상도 사진 업로드 시 압축 사용
- 오프라인 작업 후 온라인 시 즉시 동기화
- 배터리 절약을 위한 GPS 정확도 조절

### 데이터 백업 및 복구
- 일일 자동 백업 설정
- 중요 작업 데이터 수동 백업
