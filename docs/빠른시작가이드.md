# 🚀 현장관리 시스템 빠른 시작 가이드

## ⏱️ 5분만에 시작하기

### 1단계: 시설관리 프로젝트 생성 (2분)
```
시설관리 관리자 → 시설관리 프로젝트 → 새로 만들기

필수 입력 항목:
✅ 프로젝트 제목: "ABC 회사 시설관리"
✅ 연결 프로젝트: 기존 ERPNext Project 선택
✅ 계약 유형: "시설관리" 선택
✅ 서비스 주기: "주간 (평일만)" 선택
✅ 계약 시작일: 오늘 날짜
✅ 월 계약금액: 1,000,000원
```

### 2단계: 작업 지시서 생성 (2분)
```
시설관리 관리자 → 작업 지시서 → 새로 만들기

필수 입력 항목:
✅ 작업 제목: "일반 청소 작업"
✅ 시설관리 프로젝트: 1단계에서 생성한 프로젝트 선택
✅ 작업 사이트: 고객 사이트 선택
✅ 담당 직원: 현장 작업자 선택
✅ 예상 소요시간: 4시간
✅ 템플릿 설정: "템플릿" 체크
✅ 자동 반복: "활성화" 체크
✅ 반복 주기: "주간" 선택
✅ 반복 요일: "월-금 (평일)" 선택
```

### 3단계: 첫 작업 생성 및 수행 (1분)
```
작업 지시서 상세 페이지 → "Work Session 생성" 버튼 클릭
→ 실행일: 오늘 날짜 → "생성" 클릭

현장 작업자 로그인 → 내 현장 작업 → 생성된 작업 선택
→ "작업 시작" → 체크리스트 수행 → "작업 완료"
```

---

## 📱 모바일 작업자 초간단 가이드

### 출근 시
1. **체크인**: 현장 도착 → "현장 출입 기록" → "체크인"
2. **작업 시작**: "내 현장 작업" → 오늘 작업 선택 → "작업 시작"

### 작업 중
3. **체크리스트**: 각 항목 클릭하여 완료 처리
4. **사진 첨부**: 필요한 항목에 작업 사진 업로드

### 퇴근 시
5. **작업 완료**: 모든 항목 완료 후 "작업 완료"
6. **체크아웃**: "현장 출입 기록" → "체크아웃"

## 🎯 핵심 기능 요약

### 자동화 기능
- ✅ **반복 작업 자동 생성**: 설정한 주기에 따라 현장 작업 자동 생성
- ✅ **GPS 자동 수집**: 체크인/체크아웃 시 위치 자동 기록
- ✅ **시간 자동 계산**: 근무시간, 초과근무, 휴게시간 자동 계산
- ✅ **Timesheet 자동 생성**: 작업 완료 시 ERPNext Timesheet 자동 생성

### 품질 관리
- ✅ **체크리스트 표준화**: 일관된 작업 품질 보장
- ✅ **사진 증빙**: 작업 전후 사진으로 품질 검증
- ✅ **위치 검증**: GPS로 정확한 현장 작업 확인
- ✅ **평점 시스템**: 작업 품질 평가 및 피드백

### 관리 효율성
- ✅ **실시간 모니터링**: 작업 진행 현황 실시간 확인
- ✅ **성과 분석**: 작업자별 성과 및 효율성 분석
- ✅ **자동 보고서**: 일/주/월 단위 자동 보고서 생성
- ✅ **모바일 최적화**: 현장에서 즉시 사용 가능

## ⚠️ 주의사항

### 필수 확인 사항
1. **GPS 정확도**: 실외에서 사용 시 정확도 향상
2. **필수 체크리스트**: 빨간색 표시 항목은 반드시 완료
3. **사진 품질**: 선명한 사진으로 품질 검증 가능
4. **시간 기록**: 정확한 체크인/체크아웃으로 근무시간 관리

### 문제 발생 시
- **GPS 오류**: 실외 이동 후 재시도
- **체크리스트 없음**: 페이지 새로고침
- **완료 불가**: 필수 항목 완료 확인
- **기타 문제**: 시스템 관리자 문의
