# 시설 관리 앱 설계서 (Facility Management App Design)

## 1. 개요

본 앱은 고객사 시설 관리를 위한 Frappe 앱으로, 기존 ERPNext와 Frappe HR의 DocType들을 최대한 활용하여 개발합니다. 시설 관리 계약부터 현장 작업 완료까지의 전체 워크플로우를 지원합니다.

## 2. 비즈니스 워크플로우

### 2.1 전체 프로세스
1. **계약 관리**: 고객사와 시설 관리 계약 체결
2. **시설 등록**: 고객사 시설 및 장소 정보 입력
3. **업무 정의**: 수행할 업무와 체크리스트 작성
4. **작업 할당**: 시설별 업무를 직원에게 할당 및 스케줄링
5. **현장 작업**: 직원의 체크인/체크아웃 및 업무 수행
6. **보고서 생성**: 자동 보고서 생성 및 관리자/고객 전송

### 2.2 실제 운영 사례 기반 설계
- **빌딩 관리**: 사무용 빌딩의 청소, 보안, 시설점검
- **공장 관리**: 제조업체의 설비점검, 안전관리, 환경관리
- **병원 관리**: 의료기관의 위생관리, 장비점검, 환경관리
- **학교 관리**: 교육기관의 시설점검, 청소, 보안관리

## 3. 기존 DocType 활용 계획

### 3.1 고객 및 계약 관리
- **Customer**: 고객사 정보 관리 (기존 활용)
- **Address**: 고객사 주소 정보 (기존 활용)
- **Project**: 시설 관리 계약을 프로젝트로 관리 (기존 활용)
  - 사용자 정의 필드 추가:
    - `contract_type`: 계약 유형 (청소, 보안, 시설점검 등)
    - `contract_start_date`: 계약 시작일
    - `contract_end_date`: 계약 종료일
    - `service_frequency`: 서비스 주기 (일간, 주간, 월간)

### 3.2 시설 및 장소 관리
- **Asset**: 시설물 및 장비 관리 (기존 활용)
  - 사용자 정의 필드 추가:
    - `facility_type`: 시설 유형 (사무실, 화장실, 복도, 엘리베이터 등)
    - `maintenance_level`: 관리 수준 (일반, 중요, 핵심)
    - `access_requirements`: 접근 요구사항
    - `safety_notes`: 안전 주의사항
- **Location**: 위치 정보 (기존 활용)
  - 사용자 정의 필드 추가:
    - `floor_number`: 층수
    - `area_size`: 면적
    - `special_instructions`: 특별 지시사항

### 3.3 직원 및 인력 관리
- **Employee**: 직원 정보 (기존 활용)
  - 사용자 정의 필드 추가:
    - `facility_skills`: 시설 관리 기술 (청소, 보안, 전기, 배관 등)
    - `certification_info`: 자격증 정보
    - `mobile_device_id`: 모바일 기기 ID
    - `emergency_contact`: 비상 연락처

### 3.4 작업 및 업무 관리
- **Task**: 개별 작업 관리 (기존 활용)
  - 사용자 정의 필드 추가:
    - `facility_location`: 작업 시설 위치
    - `checklist_template`: 체크리스트 템플릿
    - `estimated_duration`: 예상 소요시간
    - `required_tools`: 필요 도구
    - `safety_requirements`: 안전 요구사항

### 3.5 출근 및 근태 관리
- **Attendance**: 출근/퇴근 관리 (기존 활용)
  - 사용자 정의 필드 추가:
    - `check_in_location`: 체크인 위치 (GPS 좌표)
    - `check_out_location`: 체크아웃 위치
    - `work_site`: 작업 현장
    - `attendance_photo`: 출근 인증 사진

### 3.6 시간 및 작업 기록
- **Timesheet**: 작업 시간 기록 (기존 활용)
  - 사용자 정의 필드 추가:
    - `facility_tasks`: 수행한 시설 작업들
    - `completion_photos`: 작업 완료 사진
    - `quality_rating`: 작업 품질 평가
    - `customer_feedback`: 고객 피드백

### 3.7 커뮤니케이션 및 보고
- **Communication**: 보고서 및 알림 (기존 활용)
- **Email Template**: 보고서 템플릿 (기존 활용)
- **ToDo**: 작업 할당 및 알림 (기존 활용)

## 4. 새로 생성할 DocType (최소한으로 제한)

### 4.1 Facility Checklist Template
**목적**: 시설별 체크리스트 템플릿 관리
**기존 DocType으로 대체 불가능한 이유**: Task는 개별 작업이고, 반복 사용할 체크리스트 템플릿이 필요

**필드 구성**:
- `template_name`: 템플릿 명
- `facility_type`: 시설 유형
- `checklist_items`: 체크리스트 항목들 (Child Table)
- `estimated_time`: 예상 소요시간
- `required_skills`: 필요 기술

### 4.2 Facility Work Report
**목적**: 현장 작업 완료 보고서
**기존 DocType으로 대체 불가능한 이유**: Communication은 일반적이고, 시설 관리 특화된 보고서 구조 필요

**필드 구성**:
- `employee`: 작업자
- `customer`: 고객사
- `facility_location`: 작업 위치
- `work_date`: 작업일
- `checklist_results`: 체크리스트 결과 (Child Table)
- `completion_photos`: 완료 사진들
- `issues_found`: 발견된 문제점
- `recommendations`: 권장사항
- `customer_signature`: 고객 서명 (선택)

## 5. 모바일 앱 인터페이스

### 5.1 직원용 모바일 기능
- **대시보드**: 오늘의 작업 일정
- **체크인/체크아웃**: GPS 기반 위치 확인
- **작업 목록**: 할당된 작업들
- **체크리스트**: 디지털 체크리스트 수행
- **사진 업로드**: 작업 전후 사진
- **보고서 제출**: 작업 완료 보고

### 5.2 관리자용 웹 인터페이스
- **대시보드**: 전체 작업 현황
- **직원 관리**: 직원 배치 및 스케줄링
- **고객 관리**: 고객사 및 계약 관리
- **보고서 관리**: 작업 보고서 검토 및 승인
- **분석**: 작업 효율성 및 품질 분석

## 6. 워크플로우 자동화

### 6.1 작업 할당 자동화
- 계약 정보 기반 정기 작업 자동 생성
- 직원 기술과 위치 기반 최적 할당
- 작업 우선순위 자동 설정

### 6.2 알림 시스템
- 작업 시작 전 직원 알림
- 작업 지연 시 관리자 알림
- 고객 보고서 자동 발송

### 6.3 품질 관리
- 체크리스트 완료율 모니터링
- 작업 시간 분석
- 고객 만족도 추적

## 7. 보고서 및 분석

### 7.1 운영 보고서
- 일일/주간/월간 작업 현황
- 직원별 성과 분석
- 고객별 서비스 현황

### 7.2 관리 보고서
- 계약 수익성 분석
- 자원 활용도 분석
- 품질 지표 추적

## 8. 보안 및 권한 관리

### 8.1 역할 기반 접근 제어
- **시설 관리자**: 전체 시스템 관리
- **현장 관리자**: 특정 고객사 관리
- **작업자**: 할당된 작업만 접근
- **고객**: 자사 관련 보고서만 조회

### 8.2 데이터 보안
- 고객 정보 암호화
- 작업 사진 안전 저장
- 접근 로그 관리

## 9. 구현 단계

### Phase 1: 기본 구조 (4주)
- 기존 DocType 사용자 정의 필드 추가
- 새 DocType 생성 (Checklist Template, Work Report)
- 기본 워크플로우 구현

### Phase 2: 모바일 인터페이스 (6주)
- 직원용 모바일 앱 개발
- GPS 체크인/체크아웃 기능
- 디지털 체크리스트 구현

### Phase 3: 자동화 및 분석 (4주)
- 작업 할당 자동화
- 보고서 자동 생성
- 분석 대시보드 구현

### Phase 4: 고도화 (4주)
- 고객 포털 구현
- 고급 분석 기능
- 성능 최적화

이 설계는 기존 ERPNext와 Frappe HR의 강력한 기능들을 최대한 활용하면서, 시설 관리 업무의 특수성을 반영한 효율적인 솔루션을 제공합니다.
